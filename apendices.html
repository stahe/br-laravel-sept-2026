    13. Apêndices

    13.1. Instalação do PHP

    Os exemplos e o estudo de caso exigem o [PHP] 8.4 ou uma versão posterior, com as extensões [intl] (formatação de números, exemplo 16), [pdo_mysql] (acesso ao [MySQL], exemplo 28 e estudo de caso), [mbstring], e [openssl]. Foram testados com a versão 8.4.

    No [Windows], a opção mais simples é o [Laragon] (laragon.org), que instala o [PHP], o [Composer], um servidor [MySQL] e a ferramenta de administração [HeidiSQL]. Se a versão fornecida do [PHP] for anterior à 8.4, baixe uma versão mais recente em windows.php.net/download (a versão *Thread Safe*, arquivo [.zip]), que você deve extrair na pasta [bin\php] do [Laragon]; o item PHP / [Laragon] version permite selecioná-la. O menu PHP / Extensions ativa uma extensão com um único clique ([intl], [pdo_mysql]). O terminal do [Laragon] (botão Terminal) aceita os comandos [php], [composer] e [mysql].

    Sem o [Laragon], extraia o arquivo do [PHP] em uma pasta ([C:\php]), adicione essa pasta à variável de ambiente [Path], depois crie o arquivo de configuração [php.ini] copiando [php.ini-development] e removendo o ponto e vírgula que comenta as linhas das extensões necessárias:

    1
2
3
4
    extension=intl
extension=mbstring
extension=openssl
extension=pdo_mysql

    No [macOS], o gerenciador de pacotes [Homebrew] instala o [PHP] e suas extensões padrão: [brew install php]. No [Linux] ([Ubuntu]), a versão fornecida pela distribuição costuma ser mais antiga; o repositório [ppa:ondrej/php] oferece as versões mais recentes:

    1
2
    sudo add-apt-repository ppa:ondrej/php
sudo apt install php8.4-cli php8.4-intl php8.4-mbstring php8.4-mysql php8.4-xml php8.4-curl php8.4-zip

    Verifique a instalação em um novo console:

    1
2
    php -v
php -m

    O primeiro comando deve exibir um número de versão igual ou superior a 8.4 (por exemplo, [PHP 8.4.12]); o segundo lista as extensões carregadas, incluindo [intl] e [pdo_mysql]. O comando [php --ini] indica qual arquivo, [php.ini], está sendo usado.

    13.2. Composer

    [Composer] é o gerenciador de bibliotecas do [PHP] (getcomposer.org). Ele é fornecido pelo [Laragon]; no [Windows], sem o [Laragon], usa-se seu instalador ([Composer-Setup.exe]); no [macOS], use [brew install composer]; no [Linux], siga as instruções da página getcomposer.org/download. Verifique a instalação:

    1
    composer -V

    Comandos úteis em uma pasta de projeto (aquela que contém o [composer.json]):

    1
2
3
4
    composer install            # instala as bibliotecas do projeto (pasta vendor)
composer show               # as bibliotecas instaladas
composer update             # atualiza para as versões mais recentes permitidas por composer.json
composer dump-autoload      # reconstrói o carregador de classes (após adicionar uma pasta de classes)

    [Composer] baixa as bibliotecas do repositório [Packagist] (packagist.org): é necessária uma conexão com a Internet durante a instalação. Se você estiver atrás de um proxy corporativo, especifique o proxy por meio das variáveis de ambiente [HTTP_PROXY] e [HTTPS_PROXY]. A pasta [vendor] não é copiada de uma máquina para outra (ela pode conter caminhos absolutos e é grande); ela é recriada com [composer install]. Por isso ela não está incluída no material do curso. A pasta [examples] tem sua própria pasta [vendor], compartilhada pelos 28 exemplos; o estudo de caso tem a sua.

    13.3. Instalação do Visual Studio Code

    O [Visual Studio Code] é baixado em code.visualstudio.com. Adicione duas extensões (menu View / Extensions):

    • PHP Intelephense: autocompletar código, navegação no código (inclusive no código do [Laravel], na pasta [vendor]) e relatório de erros;
    • Laravel (a extensão oficial): realce de sintaxe das views [Blade] e autocompletar para nomes de rotas, nomes de views, chaves de configuração e chaves de tradução.

    A extensão PHP Debug permite executar o código passo a passo usando o depurador [Xdebug] (uma extensão do [PHP], que deve ser instalada separadamente: xdebug.org).

    Abra a pasta [examples] ou a pasta do estudo de caso (menu File / Open Folder). O terminal integrado (menu Terminal / New Terminal) permite iniciar as aplicações sem sair do editor.

    13.4. Instalação do MySQL com o Laragon

    [Laragon] instala um servidor [MySQL] pronto para uso no [Windows], junto com a ferramenta de administração [HeidiSQL]. Após a instalação:

    • o botão "Start All" inicia o servidor [MySQL] na porta 3306;
    • o usuário [root] não tem senha: esses são os valores dos arquivos [.env] do exemplo 28 e do estudo de caso ([DB_USERNAME=root], [DB_PASSWORD=]);
    • O botão Database abre o [HeidiSQL], onde o item de menu File / Run a File (SQL) executa os scripts [dbpersons.sql] (exemplo 28) e [dbrdvmedecins2.sql] (estudo de caso).

    No [Linux] ou no [macOS], instale o [MySQL] ou o [MariaDB] usando o gerenciador de pacotes do sistema e execute os scripts com o cliente de linha de comando [mysql]. O driver [pdo_mysql] funciona com ambos sem nenhuma configuração. No [Linux], a conta [root] do [MariaDB] costuma ser configurada para permitir login apenas pela conta de sistema [root] ([sudo mysql]): cria-se então um usuário para as aplicações, e esse usuário é especificado no arquivo [.env] delas:

    1
    sudo mysql -e "CREATE USER 'course'@'localhost' IDENTIFIED BY 'course'; GRANT ALL ON *.* TO 'course'@'localhost';"

    13.5. Instalação do curl

    O [curl] vem incluído no [Windows] 10 e 11, no [macOS] e na maioria das distribuições [Linux]. No [PowerShell], você deve digitar [curl.exe], e não [curl]: nas versões mais antigas do [PowerShell], [curl] é um alias de outro comando ([Invoke-WebRequest]), que tem opções diferentes. No prompt de comando do [Windows] ([cmd]), as aspas de uma string JSON são escritas como [\"] (exemplo 11), e uma URL que contém [&] deve ser colocada entre aspas duplas.
